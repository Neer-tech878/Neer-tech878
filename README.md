### 🧠 1. SupportSense AI — Intelligent Natural Language to SQL Analytics

**[View Repository](https://github.com/Neer-tech878/SupportSense-AI)**

An AI-powered analytics system that translates natural-language questions into SQL queries and executes them against structured databases.

The goal is not simply to generate SQL, but to build a more reliable query execution pipeline with validation, error recovery, and intelligent model orchestration.

**What makes it interesting:**
- Natural-language-to-SQL generation using LLMs.
- SQL AST validation to inspect and validate generated queries before execution.
- Query execution through a FastAPI backend with SQLite integration.
- Anomaly detection and query-result handling.
- LRU caching to reduce repeated processing.
- Multi-provider LLM fallback for improved resilience.
- Bounded self-healing workflows that attempt to recover from failed queries.
- API-first architecture with a Streamlit interface.

**Tech:** Python · FastAPI · SQLite · SQLGlot · LLMs · AI Agents · Streamlit · REST APIs
